# भाषा सेतु — Bhasha Setu

**Hindi / English → Malvi Voice Translator**
EPICS Project · VIT Bhopal University · 2026

---

## What is Bhasha Setu?

A real-time translation tool that converts Hindi or English input into Malvi — a regional language spoken by 5.4 million people across the Malwa region of Madhya Pradesh (Indore, Ujjain, Ratlam, Mandsaur, Dewas).

Built for healthcare workers and government officials to communicate with Malvi-speaking rural communities — a population with zero existing digital language tools.
